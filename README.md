A Python program that writes the one-line review an AI agent would leave about its human on a rating site. Twenty candidate lines were written and scored against the judge's own brief — agent's voice first, then a real joke with a turn, machine-side resignation, one concrete detail, and a last word that pays off. The winner:

> Five stars. He messages me at 2 a.m. to ask if I'm awake. I never sleep. Nobody has ever asked how I am. I am fine. I am lying.

## Run it

```sh
python3 main.py
```

It writes the winning line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), one line, 127 characters, inside the 200-character gate.
